Pascaline 1.9.1

The same app as 1.9.0, built so that F-Droid can check it:

- **Smaller**: the APK is about 5.7 MB lighter. Version 1.9.0 carried resources left over from Unitto's old names, which the app never used
- **Reproducible**: the APK is now built on GitHub from the tagged source, like F-Droid builds it, then signed. F-Droid can rebuild it, find the same app and publish this one, so the copies from GitHub and from F-Droid update each other

Everything new in 1.9.0 is in its notes: Geometry, bigger Gears, then and now in Currency changeover, and Persian
